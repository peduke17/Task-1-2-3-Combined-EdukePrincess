## Project 2: Exploratory Data Analysis (EDA)
**Tool:** Excel  
**Goal:** Analyze the dataset to understand patterns, trends, and distributions.

**Key Findings:**
- Revenue by Products
- Monthly Revenue Trend
- First half of the total years Jan-Jun generated higher Revenue

---

## Project 3: SQL Data Analysis
**Tool:** SQL Server (SSMS)  
**Goal:** Use SQL queries to extract business insights from an e-commerce dataset.

**Queries Written:**
- SELECT with WHERE,and ORDER BY
- GROUP BY with COUNT, SUM, AVG aggregations

**Key Insights:**
- Delivered orders accounted for 19% of total orders
- Monitor was the highest revenue-generating product
- Instagram was the top referral source

E-commerce orders dataset containing 1200 rows with 14 columns including
OrderID, Product, TotalPrice, OrderStatus, ReferralSource, and PaymentMethod.
